# Sextou — site pixel art

Projeto front-end completo em HTML, CSS e JavaScript. Não precisa de Python para funcionar.

## Executar
Abra `index.html` no navegador ou, na pasta do projeto, rode:

```bash
python -m http.server 8000
```

Depois acesse `http://localhost:8000`.

## Interação principal
Clique no pirulito ou no botão “Trocar pelo chopp”. A personagem troca o pirulito pela taça de chopp de vinho, o checklist muda, o nível de sextou chega a 100% e uma animação de confetes é disparada.

A pasta `assets/` inclui a imagem de referência enviada e o conceito visual gerado durante a conversa. A personagem usada no site foi construída em CSS/pixel-art para permitir animação e interação sem depender de uma imagem estática.
